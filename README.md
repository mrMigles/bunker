# ГЛУБЖЕ

Браузерная кооперативная игра о выживании в подземном бункере после катастрофы. До 6 игроков на одну партию; свободные места занимают боты. Игроки копают новые комнаты, крутят генератор, выращивают еду, чинят фильтры, ходят на вылазки в пустошь, отбиваются от налётчиков, по ночам вместе решают, как делить пайки, и вечерами играют в карты.

- **Клиент:** TypeScript + Three.js (ортографический вид сбоку «в разрезе»), интерфейс на обычном DOM, звук и музыка генерируются через WebAudio.
- **Сервер:** Node.js + Colyseus (комнаты, транспорт, переподключение), сохранения в SQLite.
- **Общий код:** вся симуляция мира — один детерминированный модуль на TypeScript. Его используют и сервер (авторитетно), и клиент (предсказание движения), и тесты, и симулятор баланса.
- **Графика и звук полностью процедурные:** ни одного файла-ассета, всё рисуется кодом.

Архитектурные решения и отступления от исходной спецификации записаны в [DECISIONS.md](DECISIONS.md).

## Быстрый старт

Нужны **Node.js 22+** (разработка велась на Node 26) и **pnpm 10+**.

```bash
pnpm i
```

```bash
pnpm dev
```

- Клиент (Vite): <http://localhost:5173>
- Игровой сервер (Colyseus + Express): `ws://localhost:2567`, HTTP API там же.

Откройте <http://localhost:5173>, введите имя и нажмите **«Создать бункер»**. Друзья входят по 5-буквенному коду комнаты (кнопка «Войти по коду») или из списка открытых бункеров. Ссылка вида `http://localhost:5173/?code=ABCDE` сразу подключает к комнате.

> `better-sqlite3`, `esbuild` и `msgpackr-extract` собирают нативные модули. Разрешение на их сборку прописано в `pnpm-workspace.yaml` (`allowBuilds`). Если установка падает на сетевых ошибках, помогает `pnpm i --network-concurrency=4`.

## Команды

Все команды запускаются из корня репозитория.

| Команда | Что делает |
|---|---|
| `pnpm dev` | Сервер (`tsx watch`, перезапуск при изменениях) и клиент (Vite с HMR) параллельно |
| `pnpm build` | Собирает клиент в `packages/client/dist` |
| `pnpm start` | Запускает сервер; если клиент собран, сервер раздаёт его статикой |
| `pnpm test` | Все тесты Vitest (`packages/*/test/**/*.test.ts`) |
| `pnpm typecheck` | `tsc --noEmit` во всех пакетах |
| `pnpm lint` | ESLint (в `shared` запрещён `Math.random`: только детерминированный ГСЧ) |
| `pnpm format` | Prettier |
| `pnpm sim --players 6 --days 10` | Симулятор баланса: прогоняет целые партии на ботах и печатает отчёт (см. ниже) |

Вспомогательные скрипты в `packages/shared/test` запускаются напрямую:

```bash
npx tsx packages/shared/test/econ.ts
```

`econ.ts` печатает почасовую трассировку экономики (еда, вода, энергия, CO₂, износ фильтров). `smoke.ts` — быстрый прогон мира.

## Переменные окружения и порты

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `SERVER_PORT` | `2567` | Порт игрового сервера (имеет приоритет над `PORT`) |
| `PORT` | — | Используется только при `NODE_ENV=production`, если `SERVER_PORT` не задан (хостинги вроде Render/Railway/Fly) |
| `NODE_ENV` | — | `production` отключает все `debug*`-команды и отладочную панель |
| `DATA_DIR` | `./data` | Папка для базы сохранений |
| `DB_PATH` | `$DATA_DIR/saves.sqlite` | Путь к файлу SQLite |
| `EMPTY_UNLOAD_SEC` | `300` | Через сколько секунд пустая комната сохраняется и выгружается из памяти |

Клиент в режиме разработки ходит на сервер по `localhost:2567`. В продакшене клиент и сервер живут на одном origin: сервер раздаёт `packages/client/dist`.

## Как играть

### Лобби

1. Хост создаёт бункер. Остальные входят по коду.
2. Каждому игроку предлагаются **три карточки персонажа**: имя, профессия, характеристики, черты (плюс и минус), фобия, «багаж» из прошлой жизни и **скрытая личная цель**. Карточки можно перевыбрать дважды.
3. Хост настраивает партию:
   - число жильцов (1–6; недостающих добирают боты, но не больше трёх — остальные постучат в интерком или найдутся на вылазках);
   - длину дня;
   - **рассказчика** (`haven` — мягкий, `classic` — обычный, `scorched` — жёсткий);
   - режим «10 дней» (короткая партия);
   - «Засланца» (среди жильцов может оказаться предатель);
   - время хода в бою и за игровым столом;
   - поведение за столом, если игрок ушёл (доигрывает бот или пауза);
   - пропуск пролога;
   - **«Инициативу жильцов»** (включена по умолчанию, см. [Бригадир](#бригадир-инициатива-жильцов)).
4. Все жмут «Готов», хост — «Начать».

### Пролог (≈90 секунд)

Если его не пропустили, партия начинается наверху. Воет сирена, по радио ГО идёт отсчёт, на горизонте встают три ядерных гриба (вспышка, через секунду гул и дрожь земли), сыплется пепел. До последнего удара у вас минута: пробежаться по улице, схватить, что успеете (еду, воду, инструменты, памятные вещи), и спуститься в бункер. Всё, что успели донести, попадает на склад. Памятные вещи становятся декором и поднимают уют.

### Цикл дня

- **День** (06:00 → 22:00, по умолчанию 6 реальных минут). Жильцы работают, едят, отдыхают. Игроки управляют своими персонажами напрямую, остальными управляют боты.
- **Ночь — совет.** Время на паузе. Совет идёт по шагам:
  1. **Пайки:** поровну, урезать кому-то, выдать двойной.
  2. **Событие:** голосование по случившемуся за день — стук в дверь, радиопередача, моральная дилемма, абсурд.
  3. **План и сон:** доска планов на завтра, кто спит на койке, а кто на полу.
- **Утро:** газета бункера с итогами дня, новые события, проверка финала.

### Цель

Выжить и прийти к одному из финалов:

| Финал | Условие |
|---|---|
| **Ковчег** (хороший) | Собрать детали дальней рации, найти Ковчег на карте пустоши, прорваться через охрану, пока дома держат оборону |
| **Дом** (хороший) | Технология самодостаточности, гидропоника 3-го уровня и жилой отсек 2-го уровня к 30-му дню (к 8-му в коротком режиме) |
| **Дети Вспышки** (хороший) | Присоединиться к фракции через события |
| **Десять дней** (хороший) | Дожить до конца в коротком режиме |
| **Тишина** (плохой) | Все погибли |
| **Бункер пал** (плохой) | Налётчики взяли бункер |

После финала показываются хроника (все выпуски газеты), судьбы жильцов, выполненные личные цели и очки **наследия**. Хроника экспортируется в PNG. Хост может сразу начать новую партию с теми же игроками.

## Управление

### В бункере

| Клавиша | Действие |
|---|---|
| `A` / `D` | Ходьба |
| `W` / `S` | Вверх/вниз по лестнице |
| `Shift` | Бег |
| `E` | Выполнить выделенное действие (по умолчанию первое, самое важное) |
| `↑` / `↓` (или `Z` / `X`) | Выбрать другое действие в меню «Рядом с вами»; клик мышью тоже работает |
| `1`–`7` | Выбрать действие по номеру |
| `Q` | Бросить то, что в руках |
| `Tab` | Инвентарь / склад / доска бункера |
| `B` | Режим стройки (разметка комнат, отмена); `[` / `]` меняют ширину комнаты |
| `C` / `Enter` | Чат |
| `H` | «Аквариум»: отдать персонажа боту и просто смотреть (время при этом не ускоряется) |
| `F` | Вернуть камеру к своему персонажу |
| `G` | Смотреть партию за ближайшим игровым столом |
| `O` | Настройки (тени и пр.) |
| `F1`–`F4` | Эмоции: «помогите» (заодно зовёт ботов на помощь), «сюда», «нет», «ха-ха» |
| Клик по персонажу | Карточка жильца: потребности, черты, отношения |
| `~` | Отладочная панель (только в dev) |

### В вылазке (внутри здания)

| Клавиша | Действие |
|---|---|
| `A` / `D`, `W` / `S` | Движение по этажам |
| `E` | Выделенное действие из меню «Рядом с вами» (появляется само, когда рядом есть что делать) |
| Держать `E` | Быстрый обыск: в 2,5 раза быстрее, но громко (как в State of Decay 2) |
| `↑` / `↓`, `1`–`7`, мышь | Выбор действия |
| `G` | Бросить камень (отвлечь) |
| `L` | Фонарик вкл/выкл (светлее, но заметнее) |
| `Esc` | Прервать текущее действие |

### Мини-игры в бункере

Дела, которые игрок начинает сам, открывают окно мини-игры: качать рукоять насоса, крутить педали в ритм (A/D), оттирать фильтр, крутить вентиль или лампочку, мешать половником, ловить зелёную зону ключом/молотком/киркой (ПРОБЕЛ), поливать до черты, держать pH раствора, собирать плоды и давить жуков. Руками быстрее и лучше; «Пусть делает сам» закрывает окно, и персонаж доделывает в обычном темпе.

### В бою

Бой пошаговый, как в XCOM: **каждое действие выполняется сразу**. Синие клетки — можно дойти и ещё выстрелить, жёлтые — рывок. Клик по клетке — идти, по врагу — атаковать (с процентом попадания). `Enter` / `Space` — «Конец хода», после него ходят враги; `Esc` — сбросить режим прицеливания.

### За игровым столом

Мышью: щёлкнуть карту или фигуру, затем цель. Также доступны кнопки с ходами. `Esc` — встать из-за стола.

### Радио и музыка

У радио крутится ручка частоты. На музыкальных инструментах клавиши `A S D F G H J K L ;` играют ноты.

## Правила и механики

### Мир

Бункер — сетка **48 × 32 клетки**. Один «уровень» равен двум рядам клеток, всего до 16 уровней вглубь. Грунт бывает разный: земля, глина, камень, гранит, водяной карман, старый бетон и неразрушимая коренная порода. Чем твёрже порода, тем дольше копать. Комнату сначала **размечают**, потом **выкапывают** по клеткам, затем ставят **каркас** (тратятся ресурсы), и только после этого в ней появляется оборудование. Новая комната должна примыкать к существующей по горизонтали или через шахту с лестницей.

28 типов комнат: шлюз, жилой отсек, склад, техотсек, гидропоника, столовая, кухня, медпункт, мастерская, химлаборатория, грибная ферма, крольчатник, водоузел, генераторная, аккумуляторная, радиорубка, оружейная, тир, комната отдыха, часовня, карцер, лифт, опора, коридор, шахта, оборона, турельная и второй шлюз. Часть комнат закрыта технологиями. Комнаты улучшаются до 3-го уровня.

### Потребности жильца

- **Сытость, вода, бодрость, рассудок, здоровье, радиация.**
- Сытость и вода убывают постоянно. Бодрость восстанавливает сон (на койке вдвое быстрее, чем на полу; храпящие соседи мешают).
- **Рассудок** медленно дрейфует вниз. Его поднимают уютные комнаты, досуг, еда, общение, питомец, музыка и игры. Чем выше рассудок, тем меньше отдача от досуга. Голод, жажда, ранения, теснота (коек меньше, чем людей) и темнота давят на психику. При нуле случается **срыв**: жилец портит оборудование и пугает соседей.
- Здоровье падает от голода, жажды, истощения, радиации, болезней, кровотечений и CO₂. При нуле жилец **падает**, и если его не поднимут с аптечкой, умирает.

### Системы бункера

- **Энергия (кВт/кВт·ч).**
  - Генерация: велогенератор (кто-то должен крутить педали), дизель (технология + топливо), термоэлемент, солнечные панели.
  - Аккумулятор копит заряд.
  - Потребители разбиты на группы с приоритетами: воздух, вода, свет, гидропоника, кухня, мастерские, оборона, комфорт. При нехватке группы отключаются с конца списка.
- **Воздух.** CO₂ растёт от людей; фильтр воздуха чистит его, пока есть энергия и фильтр не забит.
- **Вода.** Ручной насос даёт грязную воду, водоочистка (на энергии) делает из неё чистую. Воду пьют, тратят на полив, готовку и тушение пожаров.
- **Еда.**
  - Консервы со склада и с вылазок.
  - Гидропоника: 11 культур с разным временем роста, поливом, опылением, подрезкой и вредителями.
  - Грибы, кролики, компост.
  - Кухня (12 рецептов) делает еду сытнее и вкуснее.
- **Износ.** Оборудование изнашивается и ломается; его смазывают, чистят и чинят.
- **Пожары, протечки, крысы, болезни** случаются через события.

### Дела и боты

- Состояние бункера порождает **дела** (42 вида): полить грядку, собрать урожай, почистить фильтр, смазать генератор, покрутить педали, копать, перетаскать грунт, приготовить ужин и т.д.
- Боты берут дела по срочности, профессии и расстоянию. Живут они по распорядку: утро, работа, обед, работа, ужин, досуг, сон. Болтают друг с другом, заводят отношения.
- Игрок может закрепить дело за собой или позвать бота на помощь (`F1`).

### Бригадир (инициатива жильцов)

Модуль `sim/foreman.ts`, выключается настройкой `botInitiative`. Он работает, когда игроки сами этого не делают (все игроки офлайн или в «аквариуме», либо больше суток никто ничего не размечал):

- **Размечает нужную комнату:** гидропонику, если грядок мало на число жильцов; жилой отсек, если не хватает коек; грибную ферму про запас. Место выбирается с наименьшим объёмом копки. При нехватке энергии вместо гидропоники строятся грибы, им не нужны лампы.
- **Собирает ещё один велогенератор**, если дневное потребление стабильно выше 90% возможной генерации.
- **Отправляет двух здоровых ботов на короткую вылазку** за едой или за хламом с деталями, смотря чего не хватает. Отряд бот-жильцов обыскивает место упрощённо (лут по таблице локации, риск ранений), а дорожные стычки заканчиваются ранениями и потерей части добычи, но не гибелью.

Всё, что делает бригадир, пишется в лог, и размеченную им комнату можно отменить в режиме стройки.

### Директор и события

- «Рассказчик» (`sim/director.ts`) следит за напряжением и подбирает события: 53 события в 7 категориях (дверь, внутренние, радио, мир, моральные, абсурд, линия Ковчега).
- Решения по событиям принимаются голосованием; последствия бывают отложенными.
- **Заметность** бункера растёт от шума и вылазок и приманивает налётчиков.

### Вылазки

- Отряд до 3 человек собирается у **терминала вылазок** в шлюзе. Нужно выбрать снаряжение (вес ограничен силой отряда) и выйти на **карту пустоши**.
- **Карта района Новоград** нарисована один раз (`scripts/gen-map.mjs` → `client/public/assets/wasteland-map.svg`): река Сорока и мосты, Центр, Заречье, Промзона, Вокзал, Холм, лес, воронка эпицентра. 37 мест стоят на фиксированных участках (`shared/src/data/mapslots.json`) и соединены нарисованными дорогами. Какое здание стоит на свободном участке (магазин, школа, заправка, ферма…), зависит от сида, особые места (больница, КПП у мостов, телевышка, барахолка, воронка, лагеря фракций, логово «Крысиного короля», Ковчег) всегда на своих местах. Неразведанные участки — «?».
- Время в пути идёт в игровых часах, отряд ест и пьёт свои припасы.
- **Здание** генерируется процедурно по этажам. Внутри есть контейнеры, двери (заперты, взламываются, выбиваются), угрозы, люди. Шум и фонарь влияют на обнаружение.
- **Обыск**: нажать E — тихо, держать E — в 2,5 раза быстрее, но громко (грохот может привлечь врагов). «Обыскать комнату всем отрядом» — каждый берёт свой ящик, быстро и шумно. Пока вы ищете сами, напарники стоят на стрёме. Записки и тайники замечаются сами, если стоять рядом.
- **Напарники** держат свои места вокруг лидера и переговариваются (облачка над головой).
- **Поверженные враги** оставляют тела с тем, что у них было; после боя на дороге тела можно обыскать с карты.
- Оружие попадается в обычных стеллажах и ящиках с инструментами, у тел и в шкафчиках; настолки — на «полках с настолками», в книжных шкафах, тайниках.
- Дома **радист** у терминала поддерживает отряд по радио.
- Добыча возвращается физическими предметами к шлюзу. Взяв вещь, нажмите «📥 Отнести на склад» — персонаж сам дойдёт до стеллажа. Боты тоже разносят.

### Бой

- Пошаговый в духе XCOM, на поле с укрытиями, дверями и этажами. Фаза отряда: каждое действие выполняется сразу; переход до 4 клеток — 1 ОД, до 8 — 2 ОД (всего 3 ОД). После «Конец хода» боты-союзники доигрывают, затем враги по очереди делают то, что было подписано над ними.
- Боец в 0 здоровья падает без сознания, его можно поднять аптечкой; погибает только добитый лежачий.
- Очки действия тратятся на движение, выстрел, удар, перезарядку, лечение и способности профессий.
- 12 видов врагов: от крыс и собак до солдат, дронов и босса.
- Бой полностью детерминирован (`combat/combat.ts`) и покрыт тестами.

### Вылазки без игрока

- В сборах можно «Отправить без меня»: жильцы идут сами в выбранное место. Исход — сила отряда (характеристики, оружие, здоровье, уровень) против опасности места: «чисто», «тяжело» (часть добычи, ранения) или «провал» (крохи, серьёзные раны, шанс гибели). Шансы показаны заранее. Лёгкие места боты берут уверенно, опасные без игрока почти всегда проваливают.
- Без вылазок колония гибнет: еда кончается к 4–5-му дню (`pnpm sim --initiative 0`).

### Налёты

- При высокой заметности налётчики штурмуют бункер.
- Защитники занимают позиции у шлюза, закрытый люк держит удар (баррикада добавляет прочности), турели помогают.
- Если осада затягивается, нападающие уходят.

### Прокачка

- Опыт дают работа по бункеру, обыск на вылазках, бои (больше за победу и за каждого поверженного) и возвращение с вылазки.
- Уровень (до 10) даёт +1 здоровья в бою и силу в автовылазках. На каждом уровне игрок выбирает одно из трёх умений (боты — сами): «Меткий», «Проворный» (+1 ОД), «Живучий», «Санитар», «Тень», «Мародёр», а также умения-черты: «Выносливый», «Золотые руки», «Крепкая спина», «Зелёные пальцы», «Оптимист», «Неприхотливый», «Орлиный глаз».
- Уровень и умения видны в карточке персонажа, опыт — полоской в HUD.
- **Уровень угрозы** (1–10, в верхней плашке) растёт с уровнями игроков и с днями: враги крепче и метче, в новых зданиях их больше.

### Жильцы, интерком, разговоры

- На старте не больше трёх жильцов-ботов. Новые приходят сами: **интерком** у гермодвери звонит примерно раз в два дня (первый раз — утром второго дня). Беженца можно впустить, расспросить (проверка ХАР — не разведчик ли налётчиков), накормить через щель или не открывать. Через интерком же торгуют караванщики и приходят незнакомцы из событий «у двери». Ещё жильцов находят на вылазках.
- **«💬 Поговорить»**: раз в день у каждого жильца своя история (прошлое по профессии, тревога, радость), три варианта ответа. Иногда — просьба по бункеру (почистить фильтр, починить проводку, построить комнату отдыха, принести что-то с вылазки). Она появляется в «Задачах» и засчитывается сама, когда бункер приходит в нужное состояние: +25 опыта и дружба.
- **Совет ночью** объясняет каждый шаг: что значит паёк, как голосуют, зачем план.

### Технологии

- **30 технологий** исследуются за столом в радиорубке: дизель, турели, химия, дальнее радио, лифт, улучшенные аккумуляторы, самодостаточность и др.
- Они открывают комнаты, мебель, крафт предметов и финалы.
- Мебель и уют: кресла, ковры, лампы, растения, пианино, душ, проектор, второй велогенератор и прочее.

### Досуг и атмосфера

- Радио с живыми «эфирами», газеты и вырезки (40+), кроссворды, книги.
- Рисунки на стене, кинопроектор, магнитофон, инструменты с процедурной музыкой (6 жанров), питомец.
- Дни рождения, личные цели и наследие между партиями.
- Фоновая музыка генерируется на лету и меняется по настроению: спокойная в бункере, ещё тише ночью, тревожная на вылазках, барабаны в бою.
- Гитару (из пролога или найденную на вылазке) ставят на стойку, и на ней может сыграть любой, в том числе боты на досуге.
- По утрам жильцы собираются в столовой на «кофе» из цикория: болтают, травят анекдоты, обсуждают день.
- Бункер живёт сам: далёкие взрывы трясут стены и сыплют пыль, крысы пробегают по комнатам, мигают лампы, стонут трубы, воет ветер в вентшахте; жильцы реагируют вслух.

## Архитектура

```
┌──────────── браузер (packages/client) ────────────┐
│  Three.js рендер · DOM UI · WebAudio               │
│  net.ts: применяет JSON-дельты, предсказывает      │
│  своё движение тем же stepMove, что и сервер       │
└──────────────▲──────────────────┬──────────────────┘
               │ патчи мира + fx  │ команды {k:"..."} и ввод 20 Гц
┌──────────────┴──────────────────▼──────────────────┐
│  packages/server: Colyseus GameRoom (тик 50 мс)    │
│  валидация и rate-limit команд, приватные виды,    │
│  сохранение в SQLite каждые 30 с и на смене дня    │
└──────────────▲─────────────────────────────────────┘
               │ import
┌──────────────┴─────────────────────────────────────┐
│  packages/shared: World (plain JSON) + симуляция   │
│  tickWorld · команды · действия · боты · события   │
│  бой · вылазки · настолки · данные (JSON)          │
└────────────────────────────────────────────────────┘
```

Ключевые идеи:

- **Мир — обычный JSON-объект** (`World` в `shared/src/types.ts`). Сериализуется в сохранение целиком, мигрируется при загрузке (`world/migrate.ts`).
- **Синхронизация — JSON-дельты**, а не Colyseus Schema (почему — в DECISIONS.md):
  - сервер строит публичный вид мира (`net/view.ts → publicView`) и для каждого игрока приватный (`privateView`: его рука, тайник, цель, карты за столом);
  - сравнивает с прошлым отправленным (`net/diff.ts`) и шлёт только разницу;
  - ключи, начинающиеся с `_`, никогда не уходят клиентам.
- **Детерминизм.** Вся случайность идёт через ГСЧ `sfc32` (`rng.ts`), чьё состояние хранится в мире. Одинаковый сид даёт одинаковую партию; в `shared` `Math.random` запрещён линтером.
- **Расширяемость через реестры.** Системы подключаются без правки ядра:
  - `onTick(name, phase, fn)` — пошаговые системы;
  - `registerCmd` — команды игрока;
  - `defAction` — действия с объектами (доступность, длительность, тик, завершение);
  - хуки ночи/совета/событий/боя/прибытия вылазки (`nightHooks`, `councilHooks`, `effectHooks`, `battleEndHooks`, `arriveHooks`…);
  - `modViews` — как подсистема из `w.mods` попадает в публичный и приватный вид;
  - `registerGame` — настольные игры.
- **Эффекты** (`w.fx`: звуки, тосты, вспышки, газета) рассылаются клиентам и очищаются каждый тик.
- **Время.** День длится `dayLength` реальных секунд. Ночь — это совет с паузой времени. В вылазке и в прологе время течёт по своим правилам.

## Тесты, симулятор баланса, отладка

### Тесты

```bash
pnpm test
```

Сейчас 125 тестов в 13 файлах; полный прогон занимает около минуты.

Сквозные сценарии в браузере (нужен запущенный `pnpm dev`, результаты и скриншоты — в `artifacts/e2e/`):

```bash
node scripts/e2e/newcomer.mjs
```

- `newcomer.mjs` — первая сессия новичка: лобби → пролог → первый день → вылазка → обыск → дом;
- `build.mjs` — стройка: палитра, подсвеченное место, комната построена;
- `combat.mjs` — бой в духе XCOM на тестовой арене;
- `iter3.mjs` — радио и удары в прологе, склад, мини-игра насоса, разговор, интерком, меню на вылазке, быстрый обыск, обыск комнаты, расстановка напарников, карта;
- `dangerous-sortie.mjs`, `leak-probe.mjs` — опасные вылазки и утечки GPU-памяти.

Карта района перерисовывается командой `node scripts/gen-map.mjs` (перезаписывает SVG и `mapslots.json`).

### Симулятор баланса

```bash
pnpm sim --players 6 --days 10
```

Прогоняет целые партии в одном процессе. Все жильцы на ботах, совет автоматически подтверждается. Флаги:

| Флаг | По умолчанию | Смысл |
|---|---|---|
| `--players` | 6 | Жильцов |
| `--days` | 10 | Сколько дней гнать |
| `--seeds` | 3 | Сколько разных сидов |
| `--storyteller` | `classic` | Рассказчик |
| `--daylen` | 360 | Длина дня в секундах |
| `--out` | — | Сохранить отчёт в markdown-файл |

Отчёт:

- по каждому сиду и дню: живые, еда, вода, заряд батареи, генерация/потребление энергии и доля времени с отключениями, средние и минимальные потребности, доля времени в критической зоне (< 25), события, смерти с причинами;
- средние значения по сидам;
- на что жильцы тратят время (дело, ходьба к цели, безделье с «мыслью»);
- почему боты не смогли начать дело (счётчики отказов).

Последний прогон (6 жильцов, 10 дней, 4 сида): **0 смертей на 24 жильцов**, энергия без отключений, рассудок гуляет в диапазоне 60–85. К 9–10-му дню еда становится узким местом, потому что население растёт до 7–8 человек.

### Отладка (только dev)

- `~` открывает отладочную панель: время суток, ночь, ресурсы, «разбогатеть», лечение, технологии, скорость времени, заметность, запуск любого события, все настольные игры.
- Из консоли браузера: `__net.send({ k: "debug", op: "<операция>", arg })`. Операции: `hour`, `night`, `res`, `rich`, `heal`, `tech`, `alltech`, `speed`, `notice`, `event`, `games`, `sit` (сесть за игровой стол), `table` (сбросить партию за столом, оставить N ботов).
- `__net.pub` / `__net.priv` — публичный и приватный вид мира на клиенте, `__game` — корневой UI.

## Сохранения

- Мир сохраняется в SQLite каждые 30 секунд, при смене дня и при выгрузке пустой комнаты.
- Комната без игроков выгружается через `EMPTY_UNLOAD_SEC` (по умолчанию 5 минут). Войти по тому же коду можно в любой момент: сервер поднимет мир из сохранения и мигрирует его к текущей версии.
- Наследие игроков хранится в отдельной таблице по имени и дублируется в `localStorage` браузера.
- Файл базы: `packages/server/data/saves.sqlite` (или `DB_PATH`). В git не попадает.

## Развёртывание

Один процесс Node раздаёт и игру, и статику клиента.

### Docker

Готовый образ собирает GitHub Actions (`.github/workflows/docker.yml`: типы, тесты, сборка клиента, затем образ) и публикует в GHCR при каждом пуше в `main` и на тегах `v*`:

```bash
docker compose up -d          # образ ghcr.io/mrmigles/bunker:latest → http://localhost:8080
docker compose up -d --build  # собрать образ из исходников
```

Сохранения лежат в томе `glubzhe-data` (`/data` в контейнере). Порт снаружи меняется переменной `GLUBZHE_PORT`.

### Без Docker

1. Установить зависимости:

   ```bash
   pnpm i
   ```

2. Собрать клиент:

   ```bash
   pnpm build
   ```

3. Запустить сервер в продакшен-режиме:

   ```bash
   NODE_ENV=production PORT=8080 DATA_DIR=/var/lib/glubzhe pnpm start
   ```

Советы:

- Папку `DATA_DIR` стоит вынести на постоянный диск (volume): там все сохранения.
- Если перед сервером стоит обратный прокси (nginx, Caddy), нужно пропустить WebSocket: заголовки `Upgrade` / `Connection`.
- Один процесс держит много комнат; каждая тикает 20 раз в секунду, пустые выгружаются.
