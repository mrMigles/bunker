# Отыгрыш разных ролей

## Как воспроизвести

1. Начать несколько приватных прогонов с разными стартовыми профессиями.
2. Внутри одного бункера переключиться на другого жителя через его карточку.
3. Выполнить профильное действие и личную цель каждого: стройка, разговор, лечение/химия, вылазка.
4. Сравнить доступные решения, последствия и обратную связь.

## Что исправить

- У каждой роли должна быть заметная петля: действие в бункере, действие в вылазке и личный выбор с последствиями.
- Объяснять конфликтующие черты и итоговый модификатор. В наблюдённом прогоне у учителя сочетались «Неприхотливый» и «Обжора» без пояснения результата.
- Избегать неоднозначных журналов при одинаковых именах жителей: писать профессию или портрет рядом с именем.
- После переключения роли сохранять её контекст: личная цель, открытые просьбы, полезные объекты и следующий осмысленный шаг.
