# Новый бункер

## Как воспроизвести

1. Открыть локальную игру.
2. На стартовом экране ввести имя игрока.
3. Нажать «Создать бункер», включив или выключив приватность.
4. Выбрать стартовую роль и пройти первые решения пролога.

## Снимки

| Файл | Что на снимке | Зачем нужен для улучшения |
|---|---|---|
| `pic1.png` | Экран входа: имя, создание бункера, приватность, код и список доступных комнат. | Оценить визуальную иерархию первого экрана, различимость главного действия и риск случайно вернуться не в свою комнату. |
| `pic2.png` | Будет добавлен после выбора роли и запуска пролога. | Оценить подачу ролей, целей и первого решения. |

## Что исправить

- Сделать «Создать бункер» единственным визуальным центром, а «Вернуться» — вторичным действием с кодом и датой последней игры.
- Явно подписать приватность: кто сможет увидеть комнату и что получит владелец кода.
- При совпадении названий комнат показывать код, владельца и время сохранения до входа: по одному имени нельзя уверенно выбрать свой прогон.
- Перед прологом показать короткую карточку выбранной роли: сильная сторона, уязвимость, личная цель и один пример решения, где это пригодится.
